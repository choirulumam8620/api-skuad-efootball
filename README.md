# API Skuad eFootball

Aplikasi web dan REST API berbasis **Node.js** + **Express** untuk mengelola data manajer, formasi, dan daftar pemain kunci skuad eFootball dengan penyimpanan permanen ke file JSON (`skuad.json`).

## Fitur Utama

- Menampilkan informasi manajer, formasi, dan daftar pemain kunci secara _real-time_
- Mengubah nama manajer dan formasi tim
- Menambah dan menghapus pemain langsung dari tampilan web
- Penyimpanan data permanen otomatis ke file lokal `skuad.json`

## Cara Menjalankan di Lokal

1. Instal pustaka yang dibutuhkan:
   ```bash
   npm install
   ```
